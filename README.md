# Campus Placement & Student Performance Analytics

A Python-based data analysis project developed during a 4-Day Industry Bootcamp at Integral University, Lucknow.

## Project Overview

This project analyzes a simulated dataset of 1,000 students to explore academic performance, attendance, aptitude, communication skills, internship experience, backlogs, placement outcomes and salary packages.

## Tools & Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed

- Dataset exploration
- Statistical analysis
- Sorting and filtering
- Course-wise analysis
- Gender-wise analysis
- Placement analysis
- Internship vs placement analysis
- Backlog vs placement analysis
- Study-hours analysis
- NumPy-based analysis
- Rule-based placement readiness
- Data visualization

## Visualizations

The project includes:

- Bar charts
- Pie charts
- Line charts
- Scatter plots
- Histograms
- Box plots
- Multiple-chart comparisons

## Dataset

The dataset contains 1,000 simulated student records and is intended for educational and analytical purposes.
